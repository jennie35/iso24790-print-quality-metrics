# ISO 24790 Print Quality Metrics

面向 **ISO/IEC 24790:2017 印刷图像质量相关指标复现**的 Python 项目，结合 ISOPrint Inspector 印刷质量检测软件的测量思路，研究扫描图像校准、感兴趣区域（ROI）提取及单色文本与图形的质量属性计算。

## 项目概览

项目以打印机、复印机等设备的纸质输出扫描图像为分析对象，通过 OECF 光电响应校准、MTF 空间频率响应分析与补偿，以及 ROI 定位，开展印刷质量指标的计算和可视化，为算法复现、实验对比与印刷质量分析提供参考。

仓库目前以独立实验脚本和不同算法版本为主。操作手册描述的 ISOPrint Inspector 完整软件流程用于说明项目背景；本仓库的具体能力以现有脚本为准。

| 研究环节 | 主要内容 | 代表脚本 |
| --- | --- | --- |
| OECF 校准 | 灰阶图像分析、密度与反射率转换、光电响应拟合 | `OECF.py`、`densityOECF.py`、`D-RGBoecf.py` |
| MTF 分析与补偿 | 斜边法、边缘扩散函数（ESF）、线扩散函数（LSF）、空间频率响应及频域补偿 | `MTF.py`、`SFR.py`、`targetMTF.py`、`Applied_OECFandMTF_test.py` |
| ROI 提取 | 基于配置和基准点进行几何校正与测量区域提取 | `ROItest.py` |
| 字符与线条属性 | 线宽、字符暗度、模糊度、锯齿度、字符空洞、字符周围外来标记与雾状缺陷 | `AllLineTest.py`、`LInewidthTest.py`、`CharacterDarknessTest.py` |
| 颗粒度与斑驳度 | 对不同空间尺度的亮度波动进行分析 | `GraininessAndMottle.py`、`GraininessAndMottle_onlyG.py`、`GraininessAndMottle_updates.py` |
| 条带属性 | 水平与垂直方向的明暗变化、条带指标计算及结果可视化 | `Banding.py`、`Banding2.py`、`Banding_overall.py` |

整体研究流程为：**扫描图像采集 → OECF 校准 → MTF 分析与补偿 → ROI 提取 → 属性测量 → 结果分析**。各实验脚本按其测量目标使用相应的校准数据与处理步骤，部分脚本支持将结果保存为 Excel、JSON 等格式。

手册还将大面积暗度、背景暗度、大面积空洞及背景外来标记纳入大面积图形属性模块；这些内容属于软件的测量框架，本概览不据此宣称仓库已经提供对应的完整独立实现。

## 标准依据与复现范围

[ISO/IEC 24790:2017](https://www.iso.org/standard/69796.html) 规定了硬拷贝输出中单色文本与图形的设备无关图像质量属性、测量方法和分析程序，适用于打印机和复印机产生的供人阅读的单色文档。项目围绕这一测量框架开展相关指标的研究与复现。

依据操作手册，校准环节还参考 ISO 14524 的 OECF 测量思路及 ISO 16067-1 的扫描仪空间频率响应测量思路。实际测量需要匹配的扫描分辨率、参考图像、校准数据与 ROI 配置；现有脚本中包含本地实验路径和参数，复现实验时需结合数据调整。

本项目属于研究与实验实现，尚未在本仓库中提供完整的标准符合性验证。指标名称和标准引用不代表所有算法、阈值及测量结果已通过 ISO 符合性验证。
